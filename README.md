# Local sales POS

แพ็กเกจติดตั้งและอัปเดตอย่างเป็นทางการสำหรับ Local sales บน Windows 64-bit

ตัวติดตั้งมีภาษาไทย .NET, PostgreSQL และ runtime ที่จำเป็นในตัว เลือกโฟลเดอร์และสร้างทางลัดได้

สำหรับเครื่องเดิม ให้จบหรือพักบิลและบันทึกการตั้งค่า แล้วใช้ **ตรวจอัปเดต → ติดตั้งอัปเดต** จากหน้าขายแคชเชียร์ หรือ **ตั้งค่า → ตรวจสอบอัปเดต** ของผู้ดูแล หรือแตก ZIP อัปเดตในโฟลเดอร์แยก เปิด `อัปเดตโปรแกรม.cmd` และเลือกโฟลเดอร์โปรแกรมเดิม ตัวอัปเดตคงข้อมูลร้านและการตั้งค่าเดิม

ถ้าติดตั้งทับด้วย Setup ให้ปิด Local sales และเลือกโฟลเดอร์เดิม ข้อมูลร้านอยู่ที่ `%LOCALAPPDATA%\SabaiPOS` ควรสำรองก่อนติดตั้งทับ

## หน้าขายสำหรับแคชเชียร์

บัญชี **Cashier** ล็อกอินแล้วเข้าหน้าขายโดยตรง หน้าขายใช้พื้นที่เต็ม ไม่มีเมนูจัดการร้าน สินค้า ลูกค้า รายงาน ประวัติ และตั้งค่า และป้องกันเรียกหน้าจัดการผ่านคำสั่งนำทาง

แคชเชียร์ยังสแกนสินค้า ค้นหาสินค้า เลือกลูกค้าสำหรับบิล รับเงินสดและพร้อมเพย์ พัก / เรียกบิล และพิมพ์ใบเสร็จได้ตามสิทธิ์ ปุ่มเปิด / ย่อ / ปิดจอลูกค้าอยู่หน้าหลัก กด **ตรวจอัปเดต** เพื่อเปิดหน้าต่างอัปเดตแยกโดยไม่ออกจากบิล

**Admin และ Manager** ยังใช้เมนูเดิมตามสิทธิ์ การจำกัดหน้าขายใช้เฉพาะแอป Windows ของบัญชีแคชเชียร์ ไม่เปลี่ยนข้อมูลหรือสิทธิ์ผู้ใช้ในฐานร่วม

## การชำระเงิน

แอป Windows รับ **เงินสด (F4)** และ **พร้อมเพย์ (F5)** ปิดการชำระผ่านบัตรเครดิตสำหรับทุกบัญชีแล้ว ไม่มีปุ่มบัตรเครดิตหรือคีย์ลัด F6 ข้อมูลบิลเก่าและรายงานยังคงเดิม

## รับเงินสดด้วยปุ่มจำนวนเงิน

หน้าชำระเงินสดมีปุ่ม **1, 5, 10, 20, 50, 100, 500 และ 1,000 บาท** เริ่มเงินรับที่ 0 บาท กดซ้ำเพื่อบวกยอด เช่น **100 + 50 + 50 = 200 บาท** เงินทอนเปลี่ยนทันที

กด **รับพอดี** เพื่อใส่ยอดเท่าบิล หรือ **ล้างยอด** เพื่อเริ่มนับใหม่ ยังพิมพ์ยอดเองได้ และกดปุ่มเพิ่มต่อได้ กด **ยืนยัน (ENTER)** เพื่อบันทึกบิล

## ใช้ฐานข้อมูลร่วมกับ posweb (Laravel)

เปิด **ตั้งค่า → ร้านและการชำระเงิน → ใช้ฐานข้อมูล posweb** แล้วเลือกโฟลเดอร์เว็บที่มีไฟล์ `artisan` และการตั้งค่าฐานข้อมูลเดิมใน `.env` (MySQL หรือ SQLite) บันทึกแล้วจบหรือพักบิล และปิดเปิดโปรแกรมใหม่เพื่อเริ่มใช้

Windows และเว็บใช้สินค้า สต็อก URL และรายละเอียดสินค้า ลูกค้า บิล บัญชีผู้ใช้ ข้อมูลร้าน และพร้อมเพย์ร่วมกัน คิด VAT ตามการตั้งค่าเว็บและราคาที่รวม VAT บันทึกเงินรับ เงินทอน แต้มสมาชิก และสถานะบิลให้ทั้งสองระบบอ่านตรงกัน

**โหมดร่วมใช้ข้อมูลของเว็บเป็นหลัก** เก็บ PostgreSQL เดิมไว้ ไม่มีการย้ายหรือผสานข้อมูลสองชุดอัตโนมัติ ใช้ MySQL หรือ SQLite ตามการตั้งค่าของเว็บ สำรองฐานข้อมูลผ่าน posweb ก่อนเปลี่ยนฐาน และสำรองการตั้งค่าเดิมก่อนเลือกฐานข้อมูล

ใช้บัญชีและรหัสผ่านจากเว็บ โหมดร่วมไม่สร้างบัญชีร้านตัวอย่างใหม่ การขายและการแก้สต็อกตรวจข้อมูลที่อีกระบบเพิ่งเปลี่ยน ป้องกันการขายเกินจำนวนและการเขียนทับการตั้งค่าโดยไม่แจ้ง

ในโหมดร่วม ให้มือถือใช้ **เว็บ posweb** เพื่อทำงานกับสต็อกเดียวกัน ตั้งค่า URL ที่มือถือเข้าถึงได้จากระบบเว็บ ส่วนเว็บมือถือ companion ของ Windows ใช้เมื่ออยู่ในโหมด PostgreSQL เดิม

**เปิด posweb / สำรองข้อมูล** จากหน้าตั้งค่าของ Windows เพื่อจัดการสำรองข้อมูลที่เว็บ ต้องเก็บโฟลเดอร์ posweb และฐานข้อมูลไว้ในเครื่อง การติดตั้ง Windows ไม่ได้ติดตั้ง Laravel ให้ใหม่

## พิมพ์แท็กสินค้าและพิมพ์ทั้งหมด

เปิด **สินค้า → จัดการสินค้า** เลือกสินค้า กรอก **รายละเอียดสินค้า** และ **ลิงก์หน้าเว็บสินค้า** แล้วกด **บันทึกสินค้า** แต่ละสินค้ามี URL แยกกัน ลิงก์เว้นว่างได้เมื่อยังไม่มีเว็บไซต์

กด **พิมพ์แท็กสินค้า** สำหรับสินค้าที่เลือก หรือ **พิมพ์แท็กทั้งหมด** เพื่อพิมพ์สินค้าทุกรายการครบทุกหน้า รวมสินค้าที่ปิดใช้งาน โดยไม่จำกัดช่องค้นหาหรือหมวดหมู่ที่เลือก ระบบเปิดตัวอย่างก่อนส่งพิมพ์ เริ่มต้นสินค้าละ 1 แท็ก และปรับ **จำนวนต่อสินค้า** เป็นจำนวนเดียวกันสำหรับทุกรายการได้ 1–500

แท็กแสดงชื่อ รายละเอียด Barcode และราคาตามตัวเลือก QR เปิด URL `http://` หรือ `https://` ของสินค้านั้นโดยเฉพาะ **สินค้าไม่มี URL จะไม่แสดง QR อัตโนมัติ** ไม่ต้องปิดตัวเลือกเอง สามารถปิด QR ทั้งงานพิมพ์ได้จากตัวเลือกแสดง QR

รองรับแท็ก **80 × 60 มม.**, **100 × 80 มม.** และ **A4 8 แท็ก (95 × 67.5 มม.)** งานพิมพ์ทั้งหมดเริ่ม A4 สินค้าเรียงต่อเนื่องเต็ม 8 แท็กต่อหน้า ใช้กระดาษใหม่ที่ตรงขนาดและพิมพ์ขนาดจริง 100%

แก้ลิงก์และรายละเอียดถาวรจากหน้าสินค้า งานพิมพ์ทั้งหมดใช้ข้อมูลแยกของทุกสินค้า ไม่มีช่อง URL รวม ส่วนงานพิมพ์รายการเดียวแก้ข้อความและลิงก์เฉพาะงานนั้นได้ในหน้าตัวอย่าง

ตรวจตัวอย่างก่อนพิมพ์ ข้อความยาวอาจแสดงไม่ครบ ลิงก์ยาวเกินความละเอียด QR จะให้ใช้ลิงก์สั้นลงหรือกระดาษใหญ่ขึ้น รายการที่ Barcode หรือ URL ไม่ถูกต้องจะแจ้งชื่อและ SKU ให้แก้ไขก่อนพิมพ์ทั้งหมด
## สแกนบาร์โค้ดเพื่อบันทึกและแก้จำนวนสินค้า

เปิด **สินค้า → จัดการสินค้า** สแกนในช่องด้านบนแล้วกด **Enter หรือ Tab** ระบบเปิดสินค้าตรงกับบาร์โค้ดและพาไปช่อง **จำนวนคงเหลือใหม่** ใส่ยอดคงเหลือทั้งหมดแล้วกด **บันทึกสินค้า** หรือ Enter ในช่องจำนวน รองรับศูนย์และทศนิยมไม่เกิน 3 ตำแหน่ง

บาร์โค้ดใหม่จะเติมลงฟอร์มเพิ่มสินค้า ให้กรอก SKU ชื่อ หมวดหมู่ หน่วยนับ และจำนวนแล้วบันทึก ระบบกันการสแกนทับข้อมูลที่ยังไม่บันทึก ตรวจสิทธิ์ผู้ใช้และการเปลี่ยนข้อมูลระหว่างเปิดฟอร์ม บันทึกประวัติปรับสต็อกตามเดิม

## กล้องสแกนบน Android และ iPhone

เปิดหน้าสินค้ามือถือจาก QR ใน POS แล้วกด **เปิดกล้องสแกนบาร์โค้ด** หรือ **เปิดกล้องอ่านบาร์โค้ด** ในหน้าเพิ่มสินค้า ระบบใช้กล้องหลัง อ่านภาพในมือถือโดยไม่ส่งภาพออก และนำรหัสไปค้นหาสินค้าหรือเติมฟอร์ม

ลิงก์ **HTTP ผ่าน Wi-Fi ร้าน** เปิดโหมดถ่ายภาพบาร์โค้ด ถ่ายให้ชัดแล้วกดยืนยันรูป หากเบราว์เซอร์ให้เลือกแหล่งภาพ ให้เลือกถ่ายภาพ ลิงก์ **HTTPS ที่เชื่อถือได้** ใช้กล้องสดและมีโหมดถ่ายภาพสำรอง พบสินค้าแล้วกรอกยอดคงเหลือทั้งหมดและยืนยันตรวจนับก่อนบันทึก ปิดกล้องเมื่ออ่านได้หรือกดปิด
## การรับโอนพร้อมเพย์

รับพร้อมเพย์แบบเดิม: แสดง QR ตามยอดบิล ผู้ขายตรวจรับเงินแล้วกด **ลูกค้าชำระแล้ว (ENTER)** เพื่อปิดบิล ไม่มีเมนูตรวจสลิป CheckSlips หรือ Omise Test Mode และไม่มีการเรียกบริการตรวจสลิปอัตโนมัติ แม้เคยเปิดใช้ในรุ่นก่อน

ตั้งหมายเลขพร้อมเพย์ของร้านได้ที่ **ตั้งค่า → ร้านและการชำระเงิน** ทดสอบภาพ QR ได้ในเครื่อง ใช้รับโอนและยืนยันด้วยผู้ขายตามเดิม
