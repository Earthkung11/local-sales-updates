# Local sales POS

แพ็กเกจติดตั้งและอัปเดตอย่างเป็นทางการสำหรับ Local sales บน Windows 64-bit

## รุ่นปัจจุบัน: 1.001.002

เริ่มเลขรุ่นชุดใหม่จากโค้ดล่าสุด **0.101.018** รวมปุ่ม **เปิดจอลูกค้า / ย่อจอลูกค้า / ปิดจอลูกค้า** ที่ด้านบนหน้าหลัก ใช้ได้ทั้งก่อนและหลังล็อกอิน เปิดกลับแล้วรายการขายและ QR ยังอยู่ครบ

| อัปเดตโปรแกรมเดิม | [Local-sales-1.001.002-system-update-win-x64.zip](https://github.com/Earthkung11/local-sales-updates/releases/download/v1.001.002/Local-sales-1.001.002-system-update-win-x64.zip) |

ตัวติดตั้งมีภาษาไทย .NET, PostgreSQL และ runtime ที่จำเป็นในตัว เลือกโฟลเดอร์และสร้างทางลัดได้

สำหรับเครื่องเดิม ให้จบหรือพักบิลและบันทึกการตั้งค่า แล้วใช้ **ตั้งค่า → ตรวจสอบอัปเดต → ติดตั้งอัปเดต** ในโปรแกรม หรือแตก ZIP อัปเดตในโฟลเดอร์แยก เปิด `อัปเดตโปรแกรม.cmd` และเลือกโฟลเดอร์โปรแกรมเดิม ตัวอัปเดตคงข้อมูลร้านและการตั้งค่าเดิม

ถ้าติดตั้งทับด้วย Setup ให้ปิด Local sales และเลือกโฟลเดอร์เดิม ข้อมูลร้านอยู่ที่ `%LOCALAPPDATA%\SabaiPOS` ควรสำรองก่อนติดตั้งทับ

## Omise Test Mode

เปิด **ตั้งค่า → Omise Test Mode** ใส่ **Test Secret Key (`skey_test_...`)** ของบัญชี Omise ผ่านช่องรหัสผ่านในโปรแกรม แล้วเปิดและบันทึก Test Mode ระบบเก็บ Key แบบเข้ารหัสสำหรับบัญชี Windows นี้และไม่รับ Live Key

กรอกยอด 20–150,000 บาท กด **สร้าง QR และตรวจอัตโนมัติ** ระบบตรวจสถานะทุก 3 วินาที เปลี่ยนผลทดสอบที่ **Omise Dashboard → Test Mode → Charges → เลือกรายการ → Actions → Successful หรือ Failed** หยุดตรวจหรือออกจากแท็บได้ และตรวจรายการเดิมต่อเมื่อเน็ตขัดข้องโดยไม่สร้างรายการซ้ำ

**รายการทดสอบแยกจากบิลจริง ไม่บันทึกยอดขาย ไม่ตัดสต็อก และใช้ปิดบิลจริงไม่ได้** โหมดนี้ไม่ตรวจรูปสลิปธนาคารจริง การตรวจสลิป CheckSlips สำหรับบิลจริงใช้การตั้งค่าเดิม

ต้องมี Test Secret Key และเปิดใช้ PromptPay ในบัญชีทดสอบ การทดสอบโค้ดและหน้าจอใช้บริการจำลอง ต้องใส่ Key ในโปรแกรมเพื่อทดสอบการเชื่อมบัญชีของร้าน

เอกสารผู้ให้บริการ: [Omise PromptPay](https://docs.omise.co/promptpay)

## รูปแบบเลขรุ่น

- เริ่มชุดใหม่ที่ **1.001.001** จากรุ่นล่าสุด **0.101.018**
- รุ่นปัจจุบัน **1.001.002** รุ่นถัดไปใช้ **1.001.003** ตามลำดับ
- Tag ปัจจุบันใช้ `v1.001.002` และเลขรุ่นในโปรแกรม ชื่อไฟล์ Release กับ `latest.json` ต้องตรงกัน
- โปรแกรมรุ่น `0.101.xxx` อัปเดตเข้าสู่ชุด `1.001.xxx` จาก repository นี้ได้
- Release รุ่นก่อนหน้ายังอยู่ในประวัติ สำหรับตรวจสอบและกู้คืน
