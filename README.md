รุ่นนี้ปรับป้ายสถานะจอลูกค้าเป็น **พร้อมใช้งาน** ใช้กรอบกะทัดรัดพร้อมจัดจุดสีเขียวและข้อความกึ่งกลาง แสดงวันที่และเวลาแยกสองบรรทัด คงปุ่มย่อและปิดจอ รวมทั้งสถานะระหว่างขายและรอชำระเงิน

ยอดขายภาพรวมและสต็อกในการ์ดหน้าขายอัปเดตอัตโนมัติทุก 5 วินาทีขณะที่เปิดหน้านั้น พร้อมเวลาอัปเดตล่าสุด เมื่อเน็ตขาดคงข้อมูลล่าสุดและแจ้งว่า “ข้อมูลยังไม่ล่าสุด” แล้วลองใหม่ สลับหน้าหรือออกจากระบบจะหยุดรีเฟรช หน้าขายพักการรีเฟรชระหว่างแก้บิลหรือรับเงิน ไม่เปลี่ยนบิลที่กำลังขาย คงการ์ดรูป หมวดหมู่ หน้าและตำแหน่งเลื่อน ใช้ Desktop API รุ่น 1.001.014 เดิมได้ ไม่ต้องอัปโหลด API ใหม่

## เชื่อม local4 ผ่าน API

Windows คงหน้าขายเดิม และใช้บัญชี สิทธิ์และข้อมูลของ [local4](https://local4.nexcrafttech168.com/) ผ่าน API ทุกเมนู: สินค้า สต็อก ลูกค้า สมาชิก ข้อมูลพื้นฐาน บิลพัก การขาย รายงาน ประวัติ ตั้งค่าร้าน บัญชีผู้ใช้ และโฆษณาจอลูกค้า

**ผู้ดูแลต้องติดตั้งชุด Desktop API บนเซิร์ฟเวอร์ก่อนเปิดใช้** ต้องใช้ชุด API รุ่น 1.001.014 เพื่อเปิดภาพรวมร้านและประวัติการขายให้ Cashier ชุดอัปโหลดจาก posweb เตรียมแยกสำหรับผู้ดูแล ไม่เผยแพร่ source บน repository นี้ ตรวจ `/api/desktop/version` ว่ามี `protocol: 1` ก่อนเชื่อม Windows ตรวจปลายทาง API สาธารณะบน local4 แล้วตอบ protocol: 1 ยังไม่ได้ทดสอบการขายจริงบนเว็บ

- เครื่องเดิมอัปเดตแล้วใช้การเชื่อมต่อเดิมต่อได้ Admin เลือก **ตั้งค่า → ร้านและการชำระเงิน → ใช้ API ของเว็บนี้ทุกเมนู** จากนั้นจบหรือพักบิล ปิดเปิดโปรแกรมและใช้บัญชีของเว็บ
- เครื่องใหม่ใช้ Setup ที่ตั้ง URL local4 ไว้ เข้าใช้งานได้หลังเซิร์ฟเวอร์พร้อม
- ในโหมด API ต้องเชื่อมอินเทอร์เน็ต ไม่มีการขายลงฐานในเครื่องแทนโดยอัตโนมัติ ไม่มีการย้ายหรือผสานข้อมูลร้านในเครื่องขึ้นเว็บ
- เครื่องพิมพ์และตำแหน่งจอเป็นค่าของแต่ละเครื่อง โฆษณาและข้อมูลร้านเก็บร่วมบนเว็บ มือถือเปิดเว็บ local4 เพื่อใช้ข้อมูลเดียวกัน
- ใช้ยอด VAT ส่วนลด สต็อกและแต้มจากเว็บ หากผลชำระไม่ชัดเจน เก็บคำขอเดิมแบบเข้ารหัสและตรวจผลเดิมก่อนทำซ้ำ

## หน้าขายและสินค้า

Cashier เห็นหน้าขาย ภาพรวมร้าน ประวัติการขาย สินค้าคงเหลือ และรายชื่อลูกค้า/สมาชิก โดยเมนูที่เพิ่มเป็นแบบดูข้อมูล สลับหน้าแล้วตะกร้าสินค้าเดิมยังอยู่ ส่วน Admin/Manager มีเมนูจัดการตามสิทธิ์ รับ **เงินสด (F4)** และ **พร้อมเพย์ (F5)** แบบผู้ขายตรวจรับเงินและยืนยันเอง ไม่มีชำระบัตรเครดิตหรือตรวจสลิปอัตโนมัติ

เงินสดมีปุ่ม **1, 5, 10, 20, 50, 100, 500 และ 1,000 บาท** กดซ้ำเพื่อบวกยอด รับพอดี ล้างยอด และคำนวณเงินทอน คงพัก/เรียกบิล เลือกลูกค้า ส่วนลด พิมพ์ใบเสร็จ และตรวจอัปเดต

เปิด ย่อ และปิดจอลูกค้าจากหน้าหลักได้ สแกน Barcode เพื่อค้นหาและแก้จำนวนสินค้า พิมพ์แท็กทั้งหมดหรือรายสินค้า พร้อมชื่อ รายละเอียด Barcode และ URL แยกทุกสินค้า เมื่อไม่มี URL จะไม่แสดง QR รองรับ A4 8 แท็กและแท็กม้วน 80 × 60 / 100 × 80 มม. ตรวจตัวอย่างและเลือกขนาดกระดาษของเครื่องพิมพ์ก่อนพิมพ์

## การอัปเดตเครื่องเดิม

จบหรือพักบิล บันทึกการตั้งค่าและปิด Local sales ก่อนติดตั้งทับ เลือกโฟลเดอร์เดิมเพื่อคงการตั้งค่าและข้อมูล ใช้ **ตรวจอัปเดต → ติดตั้งอัปเดต** หรือแตก ZIP ในโฟลเดอร์แยก เปิด `อัปเดตโปรแกรม.cmd` และเลือกโฟลเดอร์เดิม

Setup เริ่มต้นที่ **C:\Program Files\Local sales** และขอสิทธิ์ผู้ดูแล Windows ตอนติดตั้ง ตั้งค่าที่แก้ไขได้เก็บแยกใน **%LOCALAPPDATA%\SabaiPOS\Desktop** ไม่ต้องเปิดแอปด้วยสิทธิ์ผู้ดูแล เมื่ออัปเดตใน Program Files ให้อนุญาต UAC แล้วเปิดแอปผ่านทางลัดหลังติดตั้งเสร็จ ZIP อัปเดตคงตำแหน่งเดิม ไม่ย้ายโฟลเดอร์อัตโนมัติ

ตัวติดตั้งมี .NET และ runtime ที่จำเป็น เก็บข้อมูลและการตั้งค่าเดิมเมื่ออัปเดตหรือติดตั้งทับ การถอนการติดตั้งเก็บข้อมูลและการตั้งค่าไว้ ควรสำรองข้อมูลก่อนติดตั้ง

ทุก Release อัปเดตมีเฉพาะ ZIP อัปเดต, SHA-256 ของ ZIP และ [latest.json](https://github.com/Earthkung11/local-sales-updates/releases/latest/download/latest.json) รวม 3 ไฟล์ ชื่อ Tag เลขในโปรแกรมและ manifest ต้องตรงกัน

รุ่นนี้ผ่านการทดสอบ WPF 251 รายการ ตรวจจอลูกค้าทุกสถานะที่ความละเอียด 1024/1280/1920 และตรวจชุดอัปเดตกับการตั้งค่าเดิมด้วยข้อมูลทดสอบ ใช้ Desktop API รุ่น 1.001.014 เดิมบนเซิร์ฟเวอร์ได้ ยังไม่ได้ทดสอบการขายบน local4 จริงหรือเครื่องพิมพ์จริง
